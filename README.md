# Echoes of the Crime
<img width="1235" height="695" alt="main menu" src="https://github.com/user-attachments/assets/0f66d723-a68a-46b6-b052-52447e3feb5e" />

A murder-mystery game built in Unity where each case — suspects, clues, and
branching investigation outcomes — is generated by a fine-tuned LLM instead
of being hand-written, so no two playthroughs present the same mystery.

## How it works

1. The **Loading** scene requests a new case from a hosted LLM endpoint
   (`LLMStoryClient`, configured via `LLMEndpointConfig`) and parses the
   response into suspects, clues, and starting actions (`StoryParser`).
<img width="600" height="338" alt="loading" src="https://github.com/user-attachments/assets/6517258b-c33a-4ca9-a4c6-171278215ea5" />


2. `GameSession` carries that generated case into the **Game** scene.
<img width="582" height="328" alt="story" src="https://github.com/user-attachments/assets/3139ac50-e4db-4ef2-9900-b672fb6a9a58" />


3. The player investigates by choosing actions; each choice is sent back to
   the LLM for a contextual result and, eventually, a guess at the culprit.
<img width="600" height="338" alt="action" src="https://github.com/user-attachments/assets/6e7d460d-5c97-4238-aae0-d0e9c4e94e33" />


See [`docs/llm-training`](docs/llm-training) for the notebook used to
fine-tune the model that powers case generation.

## Tech

- Unity, C#
- TextMeshPro for UI
- A LoRA-fine-tuned LLM served from a hosted inference endpoint

## Why you can't run this from source

This repo is meant as a code reference, not a playable build — two
pieces it depends on can't be included:

- **The LLM endpoint.** Case generation talks to a private, paid
  inference endpoint serving the fine-tuned model. Its URL and API key
  live in `Assets/Config/LLMEndpointConfig.asset`, which is deliberately
  untracked — so a fresh clone has no endpoint to generate cases from,
  and the game can't get past the Loading scene.
- **The UI asset pack.** The interface uses the "Cartoon GUI Pack"
  Asset Store package, whose EULA doesn't allow redistributing the raw
  source files, so `Assets/GUIPackCartoon/` is excluded and the scenes
  reference art that isn't in the repo.
